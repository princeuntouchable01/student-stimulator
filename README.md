🎓 Student Life Simulator

«Every life starts differently. What will you do with yours?»

A lightweight, Gen-Z student life simulator where every new game creates a different student story.

Your country, background, starting situation, and other characteristics are generated by the system. From there, your decisions shape your journey through student life.

Built with a mobile-first mindset, designed to be fast, lightweight, and playable even on lower-end devices.

---

🎮 The Vision

Student Life Simulator is a game about experiencing different student lives.

You don't choose everything.

Sometimes you're lucky.
Sometimes you're not.
Sometimes you have resources.
Sometimes you have to hustle.

Every new life should feel different.

The goal is to create a fun simulation where players make decisions, face consequences, manage their student life, and discover where their randomly generated journey takes them.

---

✨ Core Features

🎲 Random Life Generation

Every new life can generate different:

- Countries
- Economic backgrounds
- Student profiles
- Starting statistics
- Circumstances

📚 Student Life

Players will eventually manage different parts of student life, including:

- Studying
- Rest
- Food
- Exploration
- Money
- Social life
- School progression

🧠 Decisions & Consequences

Player choices can affect their:

- Academic progress
- Energy
- Money
- Relationships
- Opportunities
- Future events

🌍 A Living World

Different locations, cultures, situations, and events can make each playthrough feel unique.

📱 Mobile First

The game is designed primarily for mobile devices and should remain smooth on lower-end Android phones.

⚡ Lightweight Performance

We prioritize:

- Small assets
- Efficient code
- Lazy loading
- Minimal dependencies
- Optimized images
- Local-first gameplay
- Performance over unnecessary visual effects

📲 PWA Ready

The game is planned as a Progressive Web App so players can install it and continue playing with limited or no internet connection where possible.

🧪 V1 — The First Life

The first version focuses on proving the core simulation works.

🚫 Not in V1

We are intentionally NOT starting with:

- Multiplayer
- Online accounts
- Complex backend systems
- Heavy 3D graphics
- Real-time multiplayer
- Large external APIs
- Complicated economy systems
- Huge maps

Start small. Prove it works. Then expand.

🛠️ Planned Tech Stack

- React
- TypeScript
- Vite
- CSS

The architecture should keep the game simulation logic separate from the UI, making it easier to expand the game without turning the codebase into spaghetti. 🍝

---

🏗️ Development Philosophy

Bigger by Each Success.

We will build the game incrementally:

V1 → V2 → V3 → V4 → ...

Each version should build on a stable previous version.

We do not add features simply because they sound cool.

A feature should earn its place by improving the game without damaging:

- Performance
- Stability
- Maintainability
- Player experience

If a new feature makes the game slower or unstable, we optimize before expanding further.

Contribution Rule

Before adding a major feature:

1. Create or claim an issue.
2. Create a feature branch.
3. Build and test the feature.
4. Open a Pull Request.
5. Review the changes.
6. Merge only when the feature is stable.

"main" should always remain stable.
